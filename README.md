# Новинний бот для акцій — інструкція з налаштування (iPad/iPhone, через Safari)

## Що робить бот
Раз на ~5–15 хв перевіряє новинний sentiment по тікерах з `tickers.txt`.
Якщо позитивний або негативний фон по компанії сильний (≥80%), надсилає
в Telegram нові новини по цій компанії з висновком та посиланням.

## Крок 1. Створи репозиторій на GitHub
1. Зареєструйся на github.com (якщо ще не зробив)
2. Натисни "+" → "New repository"
3. Онови поле "Repository name", наприклад `stock-news-bot`
4. Обери **Public** (важливо — для безлімітних безкоштовних хвилин Actions)
5. Натисни "Create repository"

## Крок 2. Завантаж файли
У новому репозиторії:
1. Натисни "Add file" → "Upload files"
2. Заванутаж усі файли з цього набору, зберігаючи структуру папок
   (файл `news_bot.yml` має лишитись у папці `.github/workflows/`)
3. Натисни "Commit changes"

## Крок 3. Додай секрети (ключі та токени)
У репозиторії: Settings → Secrets and variables → Actions → "New repository secret"

Додай три секрети (кожен окремо):
- `FINNHUB_API_KEY` — твій ключ з finnhub.io
- `TELEGRAM_BOT_TOKEN` — токен від @BotFather
- `TELEGRAM_CHAT_ID` — твій chat_id (дізнаєшся через `https://api.telegram.org/bot<ТОКЕН>/getUpdates` після того як напишеш щось своєму боту)

## Крок 4. Перевір, що все працює
1. Вкладка "Actions" у репозиторії
2. Обери workflow "News Bot"
3. Натисни "Run workflow" (запустити вручну, не чекаючи розкладу)
4. Перевір статус запуску (зелена галочка = успіх, червоний хрестик = помилка,
   тисни на запуск щоб побачити деталі логів)

Далі бот працюватиме сам за розкладом — навіть якщо iPad вимкнений.

## Як змінити список тікерів
1. Відкрий файл `tickers.txt` у репозиторії
2. Іконка олівця (Edit)
3. Додай/видали тікер (кожен на новому рядку)
4. "Commit changes"

Готово — наступний запуск підхопить оновлений список автоматично.

## Як змінити поріг сильного сигналу
У файлі `main.py` знайди рядок:
```
THRESHOLD = 0.80
```
Зміни число (наприклад, 0.70 для 70%) і збережи через той же спосіб (олівець → Commit).

## Типові проблеми
- **Бот мовчить** → перевір вкладку Actions, чи запускається workflow і чи немає помилок у логах
- **Помилка 401/403 від Finnhub** → неправильний або невставлений ключ у секретах
- **Помилка від Telegram** → перевір TELEGRAM_CHAT_ID (він має бути числом, іноді від'ємним для груп)
